# Genie Code

**Autonomous AI coding partner** built into every Databricks surface — notebooks, pipelines, dashboards, MLflow.

## Pain

AI assistants don't understand your data. Generic copilots suggest code that doesn't work with your tables, ignore your schemas, and hallucinate column names. Every suggestion needs manual fixing.

## Key Features

- **Unity Catalog aware** - knows your tables, columns, lineage, and governance
- **Inline autocomplete** - suggests code as you type, context-aware
- **Chat interface** - ask questions, get answers with documentation citations
- **Error diagnosis** - explains errors and offers quick fixes
- **Slash commands** - shortcuts for common operations
- **Agent modes** - adapts to your context (notebook, pipeline, dashboard, MLflow)

## Position

Any "AI-assisted development" conversation. "Unlike generic copilots, Genie Code sees your entire data catalog. It suggests joins that actually work because it knows your schema."

## How It Works

- **Integrated everywhere**: Genie Code appears in notebooks, SQL editors, pipeline builders, dashboards
- **Reads Unity Catalog**: Understands your tables, columns, types, and lineage — no hallucinated column names
- **Autocompletes in context**: Start typing and it suggests the next line based on what you're doing
- **Explains and fixes errors**: Click on an error, get an explanation, apply a suggested fix
- **Respects governance**: Only suggests assets you have access to
