# Notebooks & EDA (Exploratory Data Analysis)

**Collaborative notebooks** for interactive data exploration, visualization, and ad-hoc analysis across Python, SQL, R, and Scala.

## Pain

Data scientists work in isolated Jupyter environments, can't share state, results don't connect to production pipelines. EDA happens in silos, then gets rewritten for production.

## Key Features

- **Multi-language** — Python, SQL, R, Scala in the same notebook
- **Built-in profiling** — automatic data summaries, histograms, statistics
- **Co-editing** — real-time collaboration like Google Docs
- **Git integration** — version control, code reviews, CI/CD
- **AI-assisted coding** — Genie Code helps write and explain code

## Position

Any exploratory or ad-hoc analysis. "Before you build a dashboard, explore in a notebook. Before you train a model, profile the data here."

## How It Works

- **Pick your language**: Python, SQL, R, or Scala — switch between cells
- **Serverless or clusters**: Serverless spins up instantly; shared clusters for heavier workloads
- **Built-in profiling**: `display(df)` + "Data Profile" — summary stats, histograms, nulls without code
- **Real-time collaboration**: Colleagues see your cursor, co-edit, add comments
- **Git-integrated**: Connect to GitHub/GitLab/Azure DevOps — commit, branch, PR from the UI

## Demo Tips

- Perfect for the "let me show you the data" moment
- Data profiling: quick dataset understanding without writing code
- Collaboration: "my colleague can see what I'm doing right now"
- Starting point before dashboards or models
- Transition: notebook exploration -> SDP pipeline -> dashboard
