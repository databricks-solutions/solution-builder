# Data Quality

**Quality monitoring** for data freshness, completeness, accuracy and consistency.

## Pain

Bad data silently propagates. Dashboards show stale numbers. ML models train on corrupt data. Nobody knows until a customer complains or a report is wrong.

## Key Features

- **Freshness monitoring** - alert when data is late
- **Completeness checks** - detect missing values, null spikes
- **Accuracy rules** - business logic validation
- **Anomaly detection** - statistical outliers flagged
- **SLA tracking** - measure data delivery against expectations

## Position

Data reliability conversations. "How do you know your dashboard is showing fresh data?" "What happens when ETL fails silently?"
