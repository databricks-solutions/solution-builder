Before you start — four things you need

Two minutes of checking here saves a confusing failure three steps in.

WhatHow to check
1A catalog you can create a schema in. The workshop creates its own schema, but it can't create the catalog above it.Ask Genie Code: "which catalogs can I create a schema in?"
2Serverless compute, for notebooks and jobs. Every step uses it — the pipeline, the AI functions, the data-gen run.The compute selector at the top-right should offer Serverless.
3A SQL warehouse, running. The dashboard and the Genie space both need one.SQL Warehouses in the sidebar — start one if it's stopped.
4The Genie Assistant () enabled for your workspace. It's the thing that does the building.The panel, top-right of this notebook.

Steps 5 (Governance) and 6 (ML) are optional and use preview features — ABAC policies, UC data classification, and Discover domains (which needs MANAGE DISCOVERY). If those aren't enabled in your workspace, steps 0–4 still give you a complete, demoable story.
