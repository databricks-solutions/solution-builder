How this workshop works

You direct; Genie Code builds. Every step is a plain-English prompt you paste into the Genie Assistant — it writes the SQL, wires the pipeline, assembles the dashboard. Three moves, every step:

1
Open the Genie Assistant
The panel, top-right of any notebook.
2
Copy the prompt
Grab it from the cell and paste it in.
3
Review & run
Check what it wrote, run it, move on.

You'll build the whole stack this way — and learn to prompt it like a pro.

👉 Your first task: give Genie Code your context

Before the AI can help, it needs your context — the domain, the data you have, and what you're trying to prove. In practice you'd just point it at the business docs you already have — a PRD, a data dictionary, a requirements doc — and let it work from those. Here we've distilled that into the kit — CONTEXT.md points Genie Code at the story and the specs — so we can focus on the build.

In the notebook you just created, open Genie Code and paste this prompt once to prime it with the whole story:

Ask the Assistant

Read CONTEXT.md in this folder and the files it points to (README.md, specifications/) — they have the LuxeBeauty story and the table contract. We'll build the demo one step at a time. Confirm you've read them, summarize the story in three lines, then ask me which catalog + schema to build in if I haven't told you.
