Get the kit into your workspace

The kit unzips to this page and <slug>_workshop.zip. Keep the page in your browser; the zip goes to your workspace.

1
Import the zip
Workspace → your user folder → Import _workshop.zip. It unpacks into a _workshop folder.
2
Create a notebook in it
Same folder as CONTEXT.md, README.md, specifications/ and data_generation/.
3
Open Genie Code there
The panel, top-right of that notebook.
