A domain groups your trusted assets on the Discover page, so business users find them in one place.

  1. Open Discover in the left sidebar and click Create domain. Create the governed tag luxebeauty_operations, add a subtitle, then click Create.
  2. Ask Genie Code to tag the assets:
Ask Genie Code

Apply the governed tag luxebeauty_operations to gold_returns, gold_daily_summary and mv_returns.

  1. Back in Discover, open the domain and click Publish.

💡 Domains are in Public Preview and need the MANAGE DISCOVERY permission. Admins have it by default.
