1/ Govern PII with ABAC — tag once, one policy covers everything

ABAC (Attribute-Based Access Control) is the modern, tag-driven model: you tag sensitive columns, write one CREATE POLICY on the schema that matches those tags, and it auto-applies to every column carrying the tag — today and every future table. That's the story per-table SET MASK can't tell.
