Add global filters at the top of the dashboard that apply to all the tiles: a date range, region, product category, and a Source filter that splits "Affected lot" from "Everyday".

For Source, add the derived column CASE WHEN is_bad_lot THEN 'Affected lot' ELSE 'Everyday' END AS source to every dataset the filter should affect — the daily-summary dataset AND each gold_returns dataset. Do not put source in a dataset of its own.

Leave the forecast line chart unfiltered so the trend always shows the full picture. Republish.

⚠️ Why the prompt is so specific. An AI/BI filter only affects a widget whose own dataset contains the filtered column — there's no cross-dataset join. If the Assistant puts source in a little options-only dataset (a common shortcut), the dropdown appears and populates, and selecting a value does absolutely nothing — because no chart reads that dataset. It looks right and is inert.

✅ Confirm — don't skip this. Flip Source to "Affected lot" and watch the Refund $ counter. It must change. If the number is identical with and without the filter, the filter is bound to the wrong dataset — tell the Assistant: "the Source filter isn't affecting the KPI tiles; add the derived source column to the dataset those tiles read and rebind the filter to it."
