Ask Genie Code

Create a Genie space called "LuxeBeauty Operations Analytics".

Attach these tables:
• gold_daily_summary — daily KPIs + the weekly trend
• gold_returns — the per-return fact (product, lot, country, comment, anger)
• silver_production_lots — holds incident_summary; this is where the QC note lives, so Genie can hop here for the punchline

Give it instruction text based on what we found in the data (from our exploration in step 1 + the pipeline) — for example:
"You help Claire, a non-technical VP of Operations, analyze returns. Normal weekly returns run ~$30K at a ~8% return rate; flag anything well above that as an anomaly. When returns spike, the usual cause is a specific product batch — trace it: which products drive the returns, which production lot they share, what customers say about them, and whether that lot has an incident note in silver_production_lots explaining the root cause."

Add these sample questions (in this order):
1. What's our return rate this month, and how does it compare to baseline?
2. Why do I have so many returns? Trace it to the products and the lot.
3. Which production lot is driving the spike, and what does the QC note say?
4. What are customers saying? Show recent affected-lot comments.
5. Where are the affected customers? Group by country.
6. Are refunds recovering? Show the trend.

Finally, add a curated example query for question 3 so the drill-to-lot join is reliable: find the top lot_id in gold_returns for products SKU-1001/1002/1003, then join to silver_production_lots to return that lot's facility, production_date, status, and incident_summary.

🚦 Don't certify yet. Certification is the last thing you do, in step 7, after you've actually asked the questions and seen the answers. Certifying an agent you haven't tested is how a wrong answer ends up badged as trusted in Genie One.
