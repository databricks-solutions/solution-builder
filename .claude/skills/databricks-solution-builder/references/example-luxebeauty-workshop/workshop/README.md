# Genie Code workshop — source

This folder is the **source of truth** for the LuxeBeauty Genie Code workshop.
`build.py` turns it into `../notebooks_html/workshop.html` (generated — never edit): one
self-contained HTML (CSS, icons, JS inlined) that attendees download in the kit and open offline.

```bash
python3 build.py          # rebuild workshop.html (stdlib only)
python3 build.py --check  # fail if workshop.html is stale (use before committing)
```

## Layout

```
workshop/
├── workshop.json           page title, brand, sub-line, and "forbid" (leftover-term list)
├── notebooks/
│   └── NN_slug/            one folder per page; NN orders them and becomes the anchor (nb-NN)
│       ├── notebook.json   {"pill": "Step 1", "nav": {...}} — header tag + sidebar entry
│       └── NN_name.html    one file per cell, in filename order — plain HTML, edit freely
├── theme.css               every style a cell uses: tokens first, then one block per component
├── icons/<name>.svg        icons/logos, referenced from any HTML as <i data-icon="name"></i>
├── shell.html              page frame: <head>, sidebar, {{title}} {{brand}} {{sub}} + @@ markers
├── shell.css               page chrome (sidebar, cell frame)
├── app.js                  nav switching + Copy buttons (must work in a sandboxed iframe)
└── build.py
```

### notebook.json

```json
{"pill": "Step 3", "nav": {"num": "3", "label": "Dashboard & Genie"}}
```

- `pill` — the tag in the page header.
- `nav` — the sidebar entry, generated by `build.py` (don't hand-edit the sidebar). `num` is the
  badge (`◆` for the intro), `label` is the text. Add `"optional": true` for the "optional" tag,
  and `"divider_after": true` to draw the line after the intro. A page without `nav` has no sidebar
  entry.

### workshop.json

```json
{"title": "…", "brand": "🧴 Brand", "sub": "…", "forbid": []}
```

`forbid` lists strings that must not appear anywhere in the built page (case-insensitive). The
build **fails** if one does. The reference has none; when re-theming, set it to the reference's
story terms (LuxeBeauty, SKU-100, Lyon, Claire…) so a leftover can't ship.

## How to edit

- **Cells are free-form HTML.** Restructure, add diagrams, rewrite anything. A cell's markup is
  wrapped in `<div class="gcw cell-body">` by the build, so start straight with your content.
- **Never put `<style>` or raw `<svg>` icons in a cell.** Styles go in `theme.css` (add a new
  `/* ── .my-thing — what it is ── */` block), icons go in `icons/` and are used as
  `<i data-icon="name"></i>`. One-off data visuals (a chart drawn as SVG) can stay inline.
- **Prompts** the attendee pastes into Genie Code use this block (the Copy button copies the `<p>`):
  ```html
  <blockquote class="prompt">
    <span class="prompt-label"><span class="gc-mark"><i data-icon="genie-code"></i></span> Ask Genie Code</span>
    <button class="copy">Copy</button>
    <p>Create a Lakeflow Job that runs my pipeline…</p>
  </blockquote>
  ```
  Tips use `<blockquote class="note"><p>💡 …</p></blockquote>`.
- **Links between pages** are `href="#nb-NN"` (+ `data-target`). Write them by hand (flow strip,
  next cards); keep them in step with the folders.
- **Files are relative to the kit folder.** The attendee imports the kit folder into their
  workspace, so a cell can say `README.md`, `CONTEXT.md`, `specifications/…`, `data_generation/…` — but never
  `../` paths, and never "download the project" (the kit is the download).
- **Add / remove / reorder** pages or cells by adding, renaming or deleting folders and files
  (then `nav` in `notebook.json`).
- **Restyle / rebrand**: brand colors and fonts are the `--…` tokens at the top of `theme.css`
  (`--accent`, `--ink`, …); `shell.css` holds the sidebar look. Title/brand/sub live in `workshop.json`.

## Re-theming for a new use case

1. Rewrite `../README.md` (story + numbers), `../specifications/` (every name), `../CONTEXT.md` (the
   short primer) and `../data_generation/` for the new use case.
2. Set `workshop.json` (title, brand, sub, `forbid`).
3. Edit the cells notebook by notebook. Each file is small; you never need to read `icons/` or the
   built outputs.
4. Set each `notebook.json` `pill` and `nav`, and fix every `#nb-NN` link that changed.
5. `python3 build.py` — it fails on a leftover term or an unknown icon. Then open
   `../notebooks_html/workshop.html` and check every page renders.
