# LuxeBeauty Workshop — build the demo live with Genie Code

> **What this is.** A **hands-on workshop** variant of the LuxeBeauty returns
> demo. Instead of shipping pre-built resources, it ships a **single HTML workshop
> guide** (`notebooks_html/workshop.html`, built from `workshop/`) whose steps are
> **prompts the SA pastes into the Databricks Assistant (Genie Code)** to build the demo live, one step at a
> time: raw data (in a Volume) → SDP silver/gold → AI/BI dashboard → Genie space.
> The full pre-built demo lives at `../example-luxebeauty/`.

## The story

Same universe as `../example-luxebeauty-simple/`: LuxeBeauty Co., VP Ops Claire
Dubois sees weekly refunds spike **~4–5× to ~$140K** (baseline ~$30K) about three weeks before the latest data. Cause: three
Skincare SKUs on **one production lot** at Lyon, released despite a QC note about
a homogenizer pressure issue. The demo proves: **spot the spike on a dashboard →
ask Genie "why?" → Genie walks the data to the lot and quotes the incident note.**

## How the workshop runs

The attendee imports the kit folder into their workspace (see below), opens `workshop.html`
from it and goes through the pages in order; for each step they paste the given prompt into
the Assistant (✨) from a notebook in that folder. The Assistant reads `CONTEXT.md`, which points it
at `README.md` (story + numbers) and `specifications/` (every name), and writes the SQL/Python; the
attendee reviews + runs it.

Pages: `00_introduction` (the hub: platform + story, get the kit into the workspace, the one-time priming prompt) →
`01_setup_and_explore` → `02_build_pipeline` → `03_dashboard_and_genie` →
`04_business_semantics` → `05_governance` → `06_ml`. `01–04` are the core demo; `05`
(governance) and `06` (ML) are optional. Run only the steps the demo needs.

## The kit (what the attendee receives)

The app's Workshop-tab download builds `<slug>-workshop-kit.zip`:

```
<slug>-workshop-kit/
├── workshop.html          # copied from notebooks_html/workshop.html — opened in the browser, never uploaded
├── IMPORT.md              # generated by the app: how to import the zip
└── <slug>_workshop.zip    # imported into the workspace as-is; unpacks to <slug>_workshop/:
    ├── README.md          #   the story + key numbers
    ├── CONTEXT.md         #   the short primer Genie Code reads first
    ├── specifications/    #   every name Genie Code builds
    └── data_generation/   #   generate_data.py — raw data into the Volume
```

No `.claude/`, no transcripts. The attendee imports `<slug>_workshop.zip` (workspace Import takes a
zip, not a folder), creates a notebook in the `<slug>_workshop/` folder it unpacks to and opens Genie
Code there. So the pages assume `README.md`, `CONTEXT.md`, `specifications/` and
`data_generation/generate_data.py` sit next to the notebook.

## What's in this package

```
README.md                      # the story + key numbers (the only place for numbers)
CONTEXT.md                     # short primer: where to build, what to read, working style
resources.json                 # capabilities for every page (SDP, Dashboard, Genie, metric view, ABAC, ML…)
workshop/                      # SOURCE: one HTML file per page cell + theme.css + build.py
notebooks_html/workshop.html   # GENERATED by workshop/build.py — the downloadable guide
data_generation/generate_data.py   # writes 6 raw parquet datasets → UC Volume /raw_data/
specifications/                # every name: 01-lakeflow, 02-uc-governance, 03-ml-premium-classifier, 04-ai-bi
```

## Key design points

- **Raw lands as parquet FILES in a UC Volume** (`/Volumes/{cat}/{schema}/raw_data/`)
  — the bronze landing zone. Silver reads it via `read_files()`; **no bronze
  pass-through** (keep it simple).
- **`silver_production_lots`** exposes the lot master (incl. `incident_summary`)
  as a governed table so Genie can hop to it — the drill-down destination.
- **The SA builds everything live with Genie Code.** The workshop ships NO
  pipeline SQL — Genie Code writes it. The prompts read like a human
  prompting a real build; the specs are the grounding contract, `README.md` the story.
