# Genie Code

**Autonomous AI coding partner** built into every Databricks surface — notebooks, pipelines, dashboards, MLflow.

## Pain

Generic copilots suggest code that doesn't work with your tables, ignore schemas, hallucinate column names. Every suggestion needs manual fixing.

## Key Features

- **Unity Catalog aware** — knows your tables, columns, lineage, governance
- **Inline autocomplete** — context-aware suggestions as you type
- **Chat interface** — questions answered with documentation citations
- **Error diagnosis** — explains errors and offers quick fixes
- **Slash commands** — shortcuts for common operations
- **Agent modes** — adapts to context (notebook, pipeline, dashboard, MLflow)

## Position

Any "AI-assisted development" conversation. "Unlike generic copilots, Genie Code sees your entire data catalog. Suggests joins that actually work because it knows your schema."

## How It Works

- **Integrated everywhere**: Notebooks, SQL editors, pipeline builders, dashboards
- **Reads Unity Catalog**: Understands tables, columns, types, lineage — no hallucinated column names
- **Autocompletes in context**: Suggests next line based on what you're doing
- **Explains and fixes errors**: Click an error, get explanation, apply fix
- **Respects governance**: Only suggests assets you have access to

- Show in a notebook: "Watch it autocomplete using my actual table names"
