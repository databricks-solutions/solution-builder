# Dubois icons (Databricks workspace UI)

The 16px line icons the Databricks workspace uses for its own products (sidebar and the
"+ New" menu): workspace, catalog, notebook, query, dashboard, Genie agent, job, ETL
pipeline, SQL warehouse, compute, lakebase, app, model, serving, AI gateway, features…
Copied from the workspace UI's own SVG markup (Databricks' Dubois design system). They use
`fill="currentColor"`, so they recolour like the built-in glyphs.

Keys: `file:db/<name>`. Each file was checked for scripts, event handlers and external
links; sizes normalised to 16×16 and React-only attributes removed.
