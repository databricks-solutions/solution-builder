# PPAP Submission Summary — Kessler Drive Systems GmbH — MC-60 Mid-Drive Controller

**Document:** BWC-PPAP-KES-MC60-2023 · **Supplier:** Kessler Drive Systems GmbH, Schweinfurt (SUP-KES)
**Part:** MC-60 controller integrated in the MD-85 mid-drive unit (Trail T5) · **PPAP level:** 3 · **APPROVED 2023-12-01**

The MC-60 board is **fully potted** in polyurethane inside the mid-drive housing (IP67). Validation: 1,000 h damp heat
85/85 pass, 30 min 1 m immersion pass, ASTM B117 96 h pass. No process change notifications have been submitted since
approval. Kessler uses no conformal-coating step, so the Hanlin PCN-0419 coating change does not apply to Trail T5 bikes.
Field performance (2025–2026): controller claims ≈ 1–2 per 1,000 units per year, flat.
